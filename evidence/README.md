# Evidencias del laboratorio

En esta carpeta se almacenan las capturas utilizadas para demostrar el funcionamiento del laboratorio.

Evidencias principales:

- Topología completa en GNS3
- Configuración de políticas del FortiGate
- DHCP funcionando en VLAN 10
- USER-PC accediendo al WEB por HTTPS/443
- USER-PC bloqueado hacia DB por TCP/3306
- WEB-SERVER comunicándose con DB-SERVER por TCP/3306
- Pruebas de segmentación de red
